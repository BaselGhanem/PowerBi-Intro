المهمة

أي قسم يحتاج زيادة الموارد لتغطية العمل؟

اختار سنة 2026. للمقارنة الشهرية اختار شهرا واحدا: مارس أو أبريل.

ابدأ ببطاقات الأرقام، ثم المقارنة، ثم الرسوم. الصيغ الأساسية موجودة في نسخة البداية؛ أنشئ صيغ المقارنة الزمنية الجديدة في جدول القطاع المناسب. احذف صندوق التعليمات من مكان الرسم ثم ضع الرسم مكانه.

قاعدة مهمة

عدد الموظفين لقطة شهرية. استخدم آخر لقطة متاحة ضمن الفترة، ولا تجمع موظفي يناير وفبراير ومارس. المقارنة السابقة تعني آخر لقطة في الفترة السابقة.

لا نستخدم مجموع الموظفين منذ بداية السنة. قياس العجز سالب عند نقص الموظفين.

الصيغ المطلوبة

موجود في نسخة البداية

Last Snapshot Date

Last Snapshot Date =
MAX(FactWorkforce[Snapshot Date])
Format: yyyy-MM-dd · Last available snapshot within the current date, branch and department context.

موجود في نسخة البداية

Headcount

Headcount =
VAR LastSnapshot = [Last Snapshot Date]
RETURN
    IF(NOT ISBLANK(LastSnapshot), CALCULATE(SUM(FactWorkforce[Actual Headcount]), KEEPFILTERS(FactWorkforce[Snapshot Date] = LastSnapshot)))
Format: #,##0 · Last monthly snapshot only; never summed across months.

موجود في نسخة البداية

موجود في نسخة البداية

Staffing Gap

Staffing Gap =
[Headcount] - [Planned Headcount]
Format: #,##0 · Negative means understaffed.

موجود في نسخة البداية

Staffing Coverage %

Staffing Coverage % =
DIVIDE([Headcount], [Planned Headcount])
Format: 0.0%

موجود في نسخة البداية

Capacity Coverage %

Capacity Coverage % =
DIVIDE([Available Hours], [Required Hours])
Format: 0.0%

أنشئه أثناء التطبيق

Headcount PM

Headcount PM =
IF(HASONEVALUE(DimDate[Year Month]), CALCULATE([Headcount], DATEADD(DimDate[Date], -1, MONTH)))
Format: #,##0 · Requires one month selected; first data month returns blank.

أنشئه أثناء التطبيق

Headcount MoM %

Headcount MoM % =
DIVIDE([Headcount] - [Headcount PM], [Headcount PM])
Format: 0.0%

أنشئه أثناء التطبيق

Headcount PY

Headcount PY =
CALCULATE([Headcount], SAMEPERIODLASTYEAR(DimDate[Date]))
Format: #,##0

أنشئه أثناء التطبيق

Headcount YoY %

Headcount YoY % =
DIVIDE([Headcount] - [Headcount PY], [Headcount PY])
Format: 0.0%

أنشئه أثناء التطبيق

Staffing Coverage % PM

Staffing Coverage % PM =
IF(HASONEVALUE(DimDate[Year Month]), CALCULATE([Staffing Coverage %], DATEADD(DimDate[Date], -1, MONTH)))
Format: 0.0%

أنشئه أثناء التطبيق

Staffing Coverage Change pp

Staffing Coverage Change pp =
IF(NOT ISBLANK([Staffing Coverage % PM]), ([Staffing Coverage %] - [Staffing Coverage % PM]) * 100)
Format: 0.0 "pp"

نقاط التحقق

15 دقيقة: بطاقات الأرقام تستجيب لفلتر السنة.

30 دقيقة: المقارنة الشهرية تتغير عند اختيار مارس وأبريل، والفترة الأولى تظهر بدون مقارنة سابقة.

45 دقيقة: الاتجاه والرسم والأرقام متسقة، وفرز الأشهر صحيح.

النهاية: فلتر صفحة وفلتر رسم، تنسيق شرطي، واستنتاج واحد مرتبط برقم.

إذا تعطلت: افتح نسخة المتابعة وواصل بناء الرسوم. ارجع للصيغة لاحقا مع المدرب.
