DAX — عنوان متغير للـField Parameter

هاي المعادلة متوافقة مع Parameter اسمه Analysis By منشأ من Modeling، بشرط يحتفظ بالاعمدة الافتراضية بنفس الاسماء

Adaptive Chart Title =
VAR _choices =
    SUMMARIZE(
        'Analysis By',
        'Analysis By'[Analysis By],
        'Analysis By'[Analysis By Fields]
    )
VAR _label =
    IF(
        COUNTROWS(_choices) = 1,
        MAXX(_choices, 'Analysis By'[Analysis By]),
        "Selected Dimensions"
    )
RETURN
    "Performance by " & _label

Format visual → General → Title → Text → fx → Field value → Adaptive Chart Title

ليش مش SELECTEDVALUE للـField Parameter caption؟ لانه ممكن يتطلب Composite key. SUMMARIZE ياخذ الـCaption مع Fields column بنفس الوقت
